# ChatGPT

1. Abre **Configuración → Personalización** y activa las instrucciones
   personalizadas. Añade la [instrucción remota](README.md#instrucción-para-acceso-remoto).
2. Si trabajas dentro de un **Proyecto**, añade la misma referencia en
   **Configuración del proyecto → Instrucciones**. Las instrucciones de
   proyecto tienen precedencia sobre las personalizadas.
3. Si el chat carece de acceso al repositorio, adjunta los archivos de PAIS
   como fuentes del proyecto o en la conversación.
