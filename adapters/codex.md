# Codex

Añade la [instrucción local](README.md#instrucción-para-una-copia-local)
a `~/.codex/AGENTS.md` o al archivo equivalente bajo `CODEX_HOME`.
Si el directorio contiene un `AGENTS.override.md` aplicable, añade la
referencia allí, ya que Codex consulta ese archivo primero. Inicia una sesión
nueva para verificar la carga.

Para una sesión que corre fuera de tu equipo, usa la ruta de la copia
disponible en ese entorno o la
[instrucción remota](README.md#instrucción-para-acceso-remoto) si el agente
dispone de acceso a la URL.

[Archivos AGENTS.md en Codex](https://learn.chatgpt.com/docs/agent-configuration/agents-md)
