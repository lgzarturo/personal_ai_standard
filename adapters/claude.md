# Claude

1. En **Settings → Your Claude → Instructions**, añade la
   [instrucción base permanente](README.md#instrucción-base-permanente).
   En la configuración anterior, busca **Instructions for Claude** en
   **Settings → Account**.
2. En **Customize → Skills**, si la función está habilitada, carga
   [`pais-claude.zip`](README.md#exportar-e-instalar-la-skill) y activa la
   skill. Usa una sesión nueva para comprobar que Claude la selecciona para
   una tarea pertinente.
3. Usa **Set project instructions** para el contexto de un proyecto
   concreto. Si la skill no está disponible, añade los archivos de PAIS
   necesarios a **Project knowledge** o adjúntalos al chat.
