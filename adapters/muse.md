# Muse Code

En un repositorio de confianza, añade la
[instrucción local](README.md#instrucción-para-una-copia-local) al
`AGENTS.md` que corresponde al ámbito donde quieras usar PAIS. Conserva
las reglas existentes y evita guardar rutas personales en el repositorio
compartido. Para una sesión puntual, puedes pegar la instrucción en el chat.

Abre Muse Code en ese repositorio. Si se ejecuta fuera de tu equipo, usa
una ruta accesible desde ese entorno o la
[instrucción remota](README.md#instrucción-para-acceso-remoto)
cuando el agente pueda consultar la URL.

[Configuración e instrucciones de Muse Code](https://dev.meta.ai/docs/muse-code/configuration)
