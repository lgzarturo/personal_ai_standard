# Cursor

En Cursor, abre **Customize → Rules → User Rules** y añade la
[instrucción local](README.md#instrucción-para-una-copia-local).
La regla de usuario se aplica a **Agent**. Abre un chat nuevo de Agent
y verifica que puede leer la ruta desde el entorno en que trabaja.

Si usas un agente remoto, indica una ruta accesible desde ese entorno
o usa la [instrucción remota](README.md#instrucción-para-acceso-remoto)
en el chat cuando la URL esté disponible.

[Reglas de Cursor](https://cursor.com/docs/rules)
