# Personal AI Standard

1. Lee [BOOTSTRAP.md](references/BOOTSTRAP.md) y resuelve sus referencias
   desde el directorio `references/` de esta skill.
2. Para una tarea de proyecto, usa el catálogo adjunto y carga solo los
   perfiles pertinentes. Compara el host, propietario y repositorio completos.
   Las entradas de catálogo con el formato GitHub propietario/repositorio
   corresponden a repositorios en GitHub. Contrasta sus reglas con fuentes que
   ya estén disponibles en el entorno de trabajo o como archivos adjuntos.
3. Si falta una fuente, indica la limitación y aplica las reglas disponibles.
   Mantén las preferencias permanentes hasta que el usuario apruebe un cambio.

Las referencias están incluidas en el paquete. Trabaja con esos archivos y
con el contexto que ya esté disponible en la sesión.
