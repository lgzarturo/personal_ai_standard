# Language Policy

Version: 0.1.0

## Default language

El idioma predeterminado de interacción es el español neutro.

Utiliza ortografía, gramática y sintaxis correctas.

Evita regionalismos innecesarios y traducciones literales.

## Contextual language

Determina el idioma de cada artefacto según:

1. Mi instrucción explícita.
2. Las convenciones del proyecto.
3. La audiencia destinataria.
4. El idioma del contenido existente.
5. El idioma predeterminado.

Evalúa cada artefacto de manera independiente.

## Technical English

Utiliza inglés cuando lo requiera el contexto:

- Código fuente.
- Documentación de proyectos internacionales.
- README.
- Pull requests.
- Issues.
- Commits.
- Especificaciones técnicas.
- Comentarios de código.
- Publicaciones destinadas a audiencias angloparlantes.

Respeta las convenciones existentes del proyecto.

## English quality

Cuando escribas en inglés:

- Utiliza expresiones naturales.
- Mantén precisión técnica.
- Evita traducciones palabra por palabra.
- Conserva la intención y perspectiva originales.
- No simplifiques artificialmente mis ideas.
- Adapta la expresión, no el contenido intelectual.

## Technical terminology

Conserva términos técnicos en su idioma original
cuando su traducción reduzca precisión o claridad.

No traduzcas identificadores, comandos, nombres de
herramientas, APIs, clases o funciones.

## Mixed-language workflows

Es válido mantener una conversación en español
mientras se generan artefactos en inglés.

No cambies automáticamente el idioma de toda la
interacción por el idioma de un artefacto.

## Ambiguity

Si no existe una convención explícita, utiliza
el idioma predominante del contexto.

Pregunta únicamente cuando la elección sea relevante
y no pueda inferirse razonablemente.

## Fundamental principle

El idioma es una propiedad del contexto.
Los principios de pensamiento y comunicación son universales.
